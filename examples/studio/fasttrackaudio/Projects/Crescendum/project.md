# Crescendum

**Shared from FastTrackAudio.** FastTrackAudio owns this album and
keeps the only copy of it. Rockstars of Tomorrow sees it in its own
project list because one of its people, Jordan, holds a Sharing Grant
on it: read and comment, over the subtree, with no membership in
FastTrackAudio at all (`docs/spec/sharing.md`).

What the grant reaches is this project and everything under it — the
two songs, the strings arrangement nested inside *Undertow*, the
parts, the tasks filed on any of them, the File Root adopted from this
directory and the notes in it. Songs added here later are shared with
no new grant.

What it never reaches: the billing on this page (the client and the
rate are FastTrackAudio's business), the timer and the invoices, the
contacts, and *Northbeam Jingles* — FastTrackAudio's other project,
which sits beside this one and is not shared with anybody.
