# 31 August

Sat with [[bible::John.3.16]] again this morning, which I have read so
many times it goes past without landing. Reading the whole conversation
instead of the verse helped — it is an answer to a question Nicodemus
asked, and I had never registered that.

The bronze-serpent comparison just before it is doing more work than I
thought. [[alice.test/bible-study::John 3@2026-08-31|The wiki page]] has
the Numbers reference and the note about where the quotation might end.

Kept the sourdough going — fed at 8, peaked mid-afternoon, exactly as
[[alice.test/cooking::Sourdough Starter@2026-08-31|the recipe]] says it
should once it is established. Third time running now, so it is
genuinely reliable rather than lucky.
