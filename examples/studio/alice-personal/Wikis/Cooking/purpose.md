# Purpose

What actually worked, written down the same evening, so it can be
repeated. Alice's own wiki, in Alice's own org — unlisted, so it does
not appear in the directory, but anyone she gives the reference to can
subscribe.

## Scope

In: recipes that have been made more than once, technique notes,
substitutions that held up.

Out: recipes not yet cooked. Those stay in the vault until they earn a
page.

## Convention

A recipe page records the version that worked, not the version that was
followed. Where they differ, the difference is the useful part.
