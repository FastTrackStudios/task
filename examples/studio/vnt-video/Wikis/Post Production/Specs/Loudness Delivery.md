# Loudness Delivery

What a mix has to measure before we can hand the programme over.

| Measure | Target | Tolerance |
|---|---|---|
| Programme loudness | −23 LUFS | ±0.5 LU |
| True peak | −1 dBTP | never above |
| Loudness range | 5–15 LU | outside this, ask |

Measured over the whole programme, not per scene — a quiet first act
pulls the average down, and normalising each act separately is how a
programme that passes the check sounds wrong.

## Where the numbers come from

The broadcaster's delivery document, which is contractual. If a client's
spec disagrees with this page, the client's spec wins and this page is
what gets corrected.

## Why it is published rather than emailed

Because ACME mixes to it, and a number that lives in an email thread is a
number somebody is working from a stale copy of. They subscribe to this
wiki; when we change the figure they refresh and see it, and their own
copy says which of our states it reflects.
