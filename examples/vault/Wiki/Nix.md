# Nix

Functional package manager. Task's dev shell uses flakes — see
`flake.nix`. Provides reproducible rustup + dx + system deps + wasm
toolchain (`clang-unwrapped`, `bintools-unwrapped`).

Related: [[Cargo]], [[Crane]].
