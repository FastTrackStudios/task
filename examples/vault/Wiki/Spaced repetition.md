# Spaced repetition

Memory technique: review material at expanding intervals (1 day,
3 days, 1 week, 2 weeks, …). The interval to next review is
chosen to land just before you'd forget — re-strengthening the
memory each time.

Empirically derived from Ebbinghaus's forgetting curve. Modern
algorithms (SM-2, FSRS) tune the next interval based on review
ease: a card you got right easily gets pushed further out; one
you fumbled comes back sooner.

Apps: Anki, Mochi, RemNote. The hard part isn't the algorithm,
it's writing good cards — atomic, unambiguous, one fact per card
(same discipline as [[Zettelkasten]]).

Related: [[Zettelkasten]], [[Habit stacking]].
