# Fitness

Project tracking body metrics, workouts, and progress. Exercises live
in `[[Wiki/Exercises]]` (concept reference); instance data lives here.

- `body/` — one page per body metric (`weight.md`, `bodyfat.md`) with
  an entry log. Parsed by the `body` crate.

Future: `workouts/` (planned + completed sessions, parsed by the
`workouts` crate).
