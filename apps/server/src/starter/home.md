## How notes are sorted

Every note has **one parent**, named in its properties:

```yaml
folder: "[[Parent note]]"
```

That is the whole structure. The navigator nests each note under its parent — and a parent is a note too, so it can say what the things under it have in common. Tags are for finding, not filing: search for any of them.
