## How notes are sorted

Every note has **one parent**, named in its properties:

```yaml
folder: "[[Parent note]]"
```

That is the whole structure. The navigator's **Folders** view nests each
note under its parent — the parent is a note too, so it can say what
the things under it have in common. **Tags** shows the same notes by
every tag they carry instead. Switch between them at the top of the
navigator.
