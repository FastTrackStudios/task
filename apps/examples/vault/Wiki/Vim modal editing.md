# Vim modal editing

Distinct modes (Normal, Insert, Visual, …) where the same keys do different
things. Reduces ergonomic load on modifier keys; raises the learning curve.

Task's editor implements it via `editor-vim` — see [[Editor]] for the wider
component. The bindings table mirrors [[Vim]] and [[Neovim]].

Related: [[Helix]], [[Kakoune]], [[Modal editing]].
