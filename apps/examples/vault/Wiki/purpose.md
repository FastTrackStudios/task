# Wiki purpose

A reference knowledge base for the **Task** project — concepts and tools relevant to local-first PKM, CRDTs, modal editors, knowledge-graph visualization, and adjacent topics.

## What this wiki is for

Capture *reference* knowledge in a neutral voice — "what is X, how does X work, what's related to X." Pages here should read like glossary entries, not personal opinions. Personal claims belong in `Wisdom/`.

## Who reads it

The Task author (curator) and future LLM agents that need shared context for ingest, query, and lint passes.

## Key questions it should answer

- What's the data model behind feature X (CRDT entities, Loro, Logseq-style block refs, etc.)?
- How does tool Y compare to tool Z (Obsidian vs. Logseq vs. Dendron)?
- What's the established literature behind technique W (Adamic-Adar, Louvain, Force-directed)?
- Where does claim P trace back to (sources cited per page)?

## Out of scope

- Active project work (lives in `Projects/`)
- Daily synthesis (lives in `Daily/`)
- Personal claims and original thinking (lives in `Wisdom/`)
- Tasks and habits (lives in `tasks/`)
