# Operations

The instance / asset registry. Things that exist in the world that
projects reference — places, equipment, pantry items, vendors. Distinct
from `[[Wiki]]` (concepts, transferable knowledge): Operations is the
"what we actually have" layer.

- `[[Locations]]` — places (`home-studio.md`, `rockstars-studio.md`).
- `[[Inventory]]` — gear, equipment, household items. Includes
  `[[Pantry]]` (food items consumed by the Mealplan project).

Rule of thumb: if a thing might be referenced by more than one
project, it belongs here. Project folders hold workflow artifacts
(plans, sessions, logs), not the assets they reference.
