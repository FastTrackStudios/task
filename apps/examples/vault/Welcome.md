# Welcome to the Editor

This is the landing page of an example vault that ships with the editor.
Open it to see live-preview rendering plus cross-file resolution in action.

Everything here is plain markdown on disk — the editor adds rendering on top.

## What you can do

Use **bold**, *italic*, ==highlight==, `inline code`, and inline math like $E = m c^2$.

Linking across pages works two ways:

- Obsidian-style wikilinks: [[Project Roadmap]], [[Math reference]], [[Mermaid showcase]].
- Section links: [[Project Roadmap#Goals]] jumps inside another page.
- Logseq-style block refs: see [[Block Library]] for the reusable snippets, e.g.
  ((01950000-0000-7000-8000-000000000001)) inline.

## Embeds

A whole-page embed:

![[Project Roadmap]]

A section embed (resolves through the vault):

![[Project Roadmap#Goals]]

A block embed via Logseq form (uses the UUID directly):
